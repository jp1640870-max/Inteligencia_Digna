MIGRACIÓN SGLANG: HISTÓRICO
============================

Este documento conserva el contexto de la implementación que probó SGLang en la DGX.
SGLang ya no es el runtime de Inteligencia Digna.

La arquitectura vigente usa:

- Ollama nativo en la DGX, normalmente en `http://<IP-DGX>:51234`.
- PostgreSQL 16 con pgvector para datos y embeddings.
- MinIO/S3 para archivos y documentos.
- `lib/ollama.ts` como adaptador de inferencia.
- `migrations/` como fuente versionada del esquema.

Consulta `docs/ARQUITECTURA-NUEVA.md` y `docs/COMANDOS.md` para la puesta en marcha,
migración de datos, conexión directa desde DBeaver/VS Code y comandos actuales.

Motivo del cambio: SGLang requiere reservas de memoria por engine y la
experimentación terminó con OOM al mantener Qwen3.6, Qwen3.8, BGE-M3 y servicios
existentes en el pool unificado de 121 GB de la GB10. Ollama permite cargar y
descargar modelos según demanda y es el runtime elegido para la primera fase de
desarrollo.
